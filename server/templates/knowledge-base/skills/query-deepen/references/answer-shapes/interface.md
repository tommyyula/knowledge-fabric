# Interface Answer Shape

Use when the subject is an API, event, integration, tool call, protocol, or boundary between components.

Cover:
- caller and provider
- purpose of the interaction
- inputs, outputs, and important fields
- call sequence or timing
- success and failure behavior
- effects on business objects, workflow state, or persisted data
- compatibility, ownership, or version caveats

Keep field names and identifiers exact when the knowledge provides them.
