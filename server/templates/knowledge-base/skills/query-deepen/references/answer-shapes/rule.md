# Rule Answer Shape

Use when the user asks about a condition, permission, gate, validation, policy, eligibility rule, priority, or constraint.

Cover:
- scope of the rule
- conditions or predicates
- outcome when the rule matches
- exceptions and precedence
- where the rule is enforced
- relationship to affected workflows, interfaces, or objects
- evidence gaps or conflicting rule sources

Make negative cases explicit when they materially change the practical answer.
