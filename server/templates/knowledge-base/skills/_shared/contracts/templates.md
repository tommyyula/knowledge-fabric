# templates Contract

Use for reusable output templates: emails, notifications, reports, messages, forms, JSON payloads, or rendered response structures.

Required when supported:
- Template name and scenario.
- Subject/title when applicable.
- Body or output structure.
- Required slots/placeholders and option/checkbox fields.
- Slot data source: table, field, mapping, scenario output, user input, or interface response.
- Recipient, assignee, CC, ownership, or routing source.
- Rendering constraints: formatting, table columns, JSON shape, required sections, or review-before-send requirement.
- Related scenarios, policies, interfaces, and data tables.
