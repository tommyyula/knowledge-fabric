# business_flows Contract

Use for end-to-end workflows and processes.

Required when supported:
- Trigger and entry point.
- Actors, systems, prerequisites, and input data.
- Ordered steps, including decision points and branches.
- Required fields per input-heavy step.
- Source tables, interfaces, templates, or policies used by each step.
- Output, state transition, notification, write action, or handoff.
- Exceptions, skip conditions, retry behavior, and human review points.
- Closure criteria: how the flow completes or stops.
