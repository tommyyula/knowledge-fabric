# business_semantics Contract

Use for business concepts, metric definitions, status meanings, calculation logic, query defaults, and aggregation semantics.

Required when supported:
- Definition and business meaning.
- Applies-to scope and exclusions.
- Data sources and fields involved.
- Identification rule or classification criteria.
- Calculation, aggregation, or derivation rule.
- Default filters, default grain, default grouping, and time window.
- Query dimensions and output fields.
- Negative constraints: values to exclude, fields not to use, invalid aggregations, or cases requiring clarification.
- Related query recipes, data tables, scenarios, and reports.
