# Product

## Register

product

## Users

Ontology Studio serves builders and operators who are creating a workspace-backed knowledge base with an AI agent. They work inside an app shell while uploading source material, inspecting generated files, and asking the agent to continue structured build steps.

## Product Purpose

The product turns uploaded raw materials and user goals into a navigable wiki/ontology workspace. Success means users can see what materials were captured, preview the exact files the agent will use, reference files in chat, and confidently approve generated knowledge-base changes.

## Brand Personality

Precise, calm, craft-aware. The interface should feel like a focused knowledge-building cockpit: restrained, legible, and trustworthy rather than decorative.

## Anti-references

Avoid generic AI-purple SaaS styling, oversized rounded cards, decorative glass effects, hidden file states, and modal-heavy flows that obscure the user's current build context.

## Design Principles

- Make file provenance visible: every uploaded or generated file should have an obvious path, state, and preview affordance.
- Keep agent context explicit: when users reference files, the UI should make it clear which workspace path the agent will read.
- Preserve task flow: previews and controls should feel lightweight and reversible, not like a separate application.
- Favor dense clarity over decoration: compact lists, readable monospace paths, and restrained motion support the build workflow.
- Match the existing shell: extend current tokens and component vocabulary before introducing new visual language.

## Accessibility & Inclusion

Target WCAG AA contrast, keyboard-accessible file rows and dialogs, visible focus states, Escape/click-outside dismissal for overlays, and reduced-motion-safe transitions.
