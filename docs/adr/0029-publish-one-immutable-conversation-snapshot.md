# Publish one immutable Conversation Snapshot

The owner of a private Conversation may publish exactly one immutable snapshot of its user-visible messages behind a permanent, unguessable bearer link. Re-sharing returns the same link, later messages never update it, and anonymous readers receive no Knowledge Base, resource, file, tenant, or follow-up access. This deliberately favors a stable one-click sharing contract over live synchronization, link management, expiry, or revocation state.

Deleting the source Knowledge Base does not remove the independent snapshot, but deleting the source Conversation or owner account does. The public representation excludes attachments, internal paths, clickable citations, system content, reasoning, and tool activity.
